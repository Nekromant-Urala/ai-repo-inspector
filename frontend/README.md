# Фронтэнд AI-Repo Inspector

Angular 19, TypeScript, Reactive Forms и RxJS. Реализованы страницы отправки проекта, ожидания, отчёта и 404.

## Локальный запуск

Из каталога `frontend`:

```sh
npm ci
npm start
```

Приложение открывается на `http://localhost:4200`. Запросы `/api` проксируются на `http://127.0.0.1:8080`; бэкенд должен быть запущен отдельно по инструкции корневого README.

Другой порт:

```sh
npm start -- --host 127.0.0.1 --port 4201
```

Production-сборка:

```sh
npm run build
```

Результат: `dist/ai-repo-frontend/browser/`. Dockerfile фронтэнда раздаёт эту папку через Nginx. Ожидание ответа анализа в Nginx увеличено до 600 секунд.

## Доступные сценарии

Форма принимает публичную ссылку GitHub/GitLab, ZIP до 50 МиБ или список ссылок в TXT (UTF-8, одна ссылка на строку, до 20 уникальных адресов). При пакетном запуске одновременно проверяются до трёх проектов. Результаты появляются в таблице по мере готовности. Страница отчёта получает сохранённые данные по ID.

Один набор дополнительных критериев применяется ко всем проектам в списке. Описание вида «Файл: README.md» проверяет наличие файла относительно корня проекта и даёт 100 или 0 баллов. Остальные формулировки выводятся для ручной оценки. Дополнительные критерии отображаются отдельно от среднего балла встроенных анализаторов.

## Ручная проверка

После сборки фронтенда проверьте отправку ссылки и ZIP, изменение критериев и загрузку TXT. В таблице откройте отчёт и обновите страницу. Для полного цикла запустите бэкенд и PostgreSQL.
